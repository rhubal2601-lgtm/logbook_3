# logbook – Installation

**Veröffentlichen (GitHub Pages):** 1) Neues GitHub-Repository anlegen. 2) Alle Dateien dieses Ordners (index.html im Hauptverzeichnis) hochladen. 3) Settings → Pages → „Deploy from a branch“ → main / (root) → Save. 4) Nach ca. 1 Minute erreichbar unter https://DEINNAME.github.io/REPO/

**iPhone:** In Safari öffnen → Teilen → „Zum Home-Bildschirm“.
**Android:** In Chrome öffnen → Menü ⋮ → „App installieren“ / „Zum Startbildschirm hinzufügen“.

Danach funktioniert die App offline. Alle Daten liegen nur lokal im Gerät. Gerätewechsel: Backup & Einstellungen → JSON exportieren, am anderen Gerät importieren. Regelmäßig Backups machen!
